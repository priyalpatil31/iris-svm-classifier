// 01 — Foundation

What is Cloud Computing?

The backbone of modern digital infrastructure — delivering computing resources over the internet on demand.

Computing Without Boundaries

Cloud computing is the on-demand delivery of IT resources — including computing power, storage, databases, networking, analytics, machine learning, and more — over the internet ("the cloud"). It replaces traditional on-premise servers and infrastructure with flexible, scalable, pay-as-you-go services.

Instead of buying, owning, and maintaining physical data centers and servers, organizations can access technology services on an as-needed basis from a cloud provider like Amazon Web Services (AWS), Microsoft Azure, or Google Cloud Platform.

Key benefits include: massive cost savings, global scalability in minutes, high availability, automatic updates, and security at enterprise scale — all without managing physical hardware.

🏗️

IaaS — Infrastructure as a Service

Provides fundamental computing resources: virtual machines, storage, and networking. You manage the OS and above. Examples: AWS EC2, Azure VMs.

🛠️

PaaS — Platform as a Service

Provides a managed runtime environment for building and deploying applications. No server management needed. Examples: AWS Elastic Beanstalk, Heroku.

📦

SaaS — Software as a Service

Fully managed software accessible via browser. No installation or maintenance. Examples: Gmail, Salesforce, Microsoft 365.

☁️

Deployment Models

Public Cloud (shared, AWS), Private Cloud (dedicated, on-premise), Hybrid Cloud (combination of both for flexibility and compliance).

Amazon S3

Simple Storage Service

Amazon S3 is an object storage service offering industry-leading scalability, data availability, security, and performance. It stores and retrieves any amount of data from anywhere on the web — from websites and mobile apps to enterprise applications.

  • Store unlimited files as objects in "buckets"
  • 99.999999999% (11 nines) durability guarantee
  • Granular access control with bucket policies
  • Versioning to keep multiple variants of an object
  • Static website hosting directly from S3
  • Lifecycle rules to automate data archival to Glacier
📦

Creating S3 Buckets

Bucket Configuration & Management

Buckets are the fundamental containers in S3 for data storage. Creating and configuring them correctly is essential for organizing cloud data, controlling access, enabling encryption, and optimizing costs across AWS regions.

  • Choose an AWS region closest to end users for low latency
  • Enable Block Public Access for private data security
  • Configure bucket policies using JSON IAM syntax
  • Enable server-side encryption (SSE-S3 or SSE-KMS)
  • Set up Cross-Region Replication (CRR) for redundancy
  • Monitor access logs and storage metrics via CloudWatch
💻

Amazon EC2

Elastic Compute Cloud

EC2 provides resizable compute capacity in the cloud. It allows you to launch virtual machines (called instances) of any size, install any software, and run any application — all with complete control and flexibility.

  • Choose from 500+ instance types (t3.micro to high-memory)
  • Use Amazon Machine Images (AMIs) to launch preconfigured instances
  • Auto Scaling groups to scale capacity automatically with demand
  • Elastic Load Balancing to distribute traffic across instances
  • Security Groups act as virtual firewalls per instance
  • Spot Instances for up to 90% savings on batch workloads
🔐

AWS IAM

Identity and Access Management

IAM enables you to manage access to AWS services and resources securely. Using IAM, you can create and manage AWS users, groups, roles, and permissions to control who can access what — following the principle of least privilege.

  • Create IAM Users for individual AWS console/API access
  • Organize users into Groups with shared permission policies
  • Attach JSON Policies to define allowed/denied actions
  • Create Roles for services (EC2 accessing S3 without keys)
  • Enable Multi-Factor Authentication (MFA) for security
  • Use IAM Access Analyzer to identify over-permissive policies
🌐

Amazon VPC

Virtual Private Cloud

A VPC is your own logically isolated section of the AWS Cloud where you can launch AWS resources in a virtual network you define. You have complete control over your networking environment, including IP addressing, subnets, routing tables, and gateways.

  • Define custom IP address ranges using CIDR notation
  • Create public subnets (for web servers) and private subnets (for DBs)
  • Internet Gateway to enable communication with the internet
  • NAT Gateway for private subnet outbound internet access
  • VPC Peering to connect two VPCs privately
  • Network ACLs for subnet-level traffic filtering
📊

AWS CloudWatch

Monitoring & Observability

CloudWatch provides monitoring for AWS cloud resources and applications. It collects and tracks metrics, monitors log files, sets alarms, and automatically reacts to changes in your AWS resources — giving full visibility into your cloud operations.

  • Collect and visualize metrics from EC2, S3, Lambda, and more
  • Set threshold-based alarms that trigger SNS notifications
  • Centralize application and system logs with Log Groups
  • Create custom dashboards for real-time infrastructure views
  • Use CloudWatch Events to trigger automated responses
  • Analyze logs with CloudWatch Insights using SQL-like queries

Cloud IDE with CodeAnywhere

Browser-based collaborative development environment — code, collaborate, and deploy from any device, anywhere.

🌍

Cloud-Based Development

CodeAnywhere is a cloud IDE that lets you code directly in your browser without installing anything locally. Your development environment lives in the cloud — accessible from any laptop, tablet, or computer with an internet connection.

🤝

Real-Time Collaboration

Share your workspace with teammates or instructors for real-time pair programming. Multiple users can view and edit code simultaneously — just like Google Docs but for code, complete with a shared terminal.

🐳

Containers & Dev Boxes

Each workspace runs in an isolated Linux container. You can SSH into it, run servers, install packages, and execute code — a full development environment pre-configured with languages like Python, Node.js, PHP, and more.

🔗

Git & GitHub Integration

Clone repositories directly from GitHub, GitLab, or Bitbucket. Commit, push, pull, and branch without leaving the browser. Combine this with AWS for a complete cloud-native development workflow.

⚡

Instant Preview & Deploy

Run your web app inside the container and access it via a public preview URL. Deploy directly to services like AWS, Heroku, or DigitalOcean without manual server configuration — accelerating the dev-to-production cycle.

// 04 — Virtualization

Virtual Machines with VMware

The foundation of cloud computing — running multiple isolated operating systems on a single physical machine.

What is Virtualization?

Virtualization is the process of creating a software-based (virtual) version of a computer, including virtual computer hardware, storage, and networking. VMware pioneered this technology and remains the industry leader in enterprise virtualization solutions.

A single physical server running VMware can host dozens of virtual machines, each behaving like a completely independent computer with its own OS, applications, and resources. This is the core technology that powers cloud data centers worldwide.

In our coursework, we used VMware Workstation to create, configure, and manage virtual machines locally — understanding the same technology that AWS EC2 uses at massive scale.

Guest OS (Windows / Linux VM)
Virtual Hardware (vCPU, vRAM, vDisk)
VMware Hypervisor (Type 1 / Type 2)
Host Operating System
Physical Hardware (CPU, RAM, Storage, NIC)
🖥️

Creating Virtual Machines

Using VMware Workstation, we created VMs step-by-step: selecting ISO images, allocating vCPUs and RAM, configuring virtual hard disk size, choosing network adapter type (NAT, Bridged, Host-only), and completing OS installation.

📸

Snapshots & Rollback

VMware's snapshot feature captures the entire VM state at a point in time. If an update or configuration change breaks something, you can instantly roll back to the last snapshot — similar to a system restore point but far more powerful.

🌐

Virtual Networking

Configured virtual network adapters in three modes — Bridged (VM gets its own IP on LAN), NAT (VM shares host IP), and Host-Only (isolated private network). This mirrors how cloud VPCs and subnets work at scale.

📦

VM Templates & Cloning

Created base VM templates with pre-installed software, then cloned them rapidly to spin up multiple identical environments. This same concept is how AWS AMIs allow instant EC2 instance creation from a master image.

⚡

Resource Allocation

Learned to dynamically adjust vCPU cores, RAM, and disk space allocated to running VMs — understanding how overcommitting physical resources affects performance and how cloud providers manage multi-tenant environments.

🔄

Hypervisor Types

Type 1 (Bare Metal) hypervisors like VMware ESXi run directly on hardware without a host OS — used in data centers and AWS. Type 2 (Hosted) like VMware Workstation run on top of an OS — perfect for learning and development.
